# Thermocouple-Based Milk Pasteurization Monitoring System (NI myRIO & LabVIEW)

An end-to-end electronic instrumentation and virtual telemetry system designed for laboratory-scale milk pasteurization monitoring across the critical 60 °C to 75 °C thermal band. The platform interfaces a Type-K thermocouple through an analog signal conditioning circuit into an NI myRIO data acquisition (DAQ) device, providing real-time data processing, process stability calculation, and automated stage classification in LabVIEW.

---

### System Architecture

The physical measurement pipeline converts low-level thermoelectric microvolt signals into an amplified 0–5 V analog signal compatible with the NI myRIO ADC:

Key Capabilities & Engineering DesignDual-Stage Signal Conditioning: Amplifies low-level thermocouple output ($2.436\text{ mV}$ to $3.059\text{ mV}$) through two cascaded TL081 JFET operational amplifiers to achieve an aggregate system gain of approximately $8000$, mapping the $60\text{–}75\text{ }^\circ\text{C}$ range across $0\text{–}5\text{ V}$.   Active Zero-Offset Reference: A precision voltage divider ($R_1 = 205\text{ k}\Omega$, $R_2 = 100\text{ }\Omega$ from a $5\text{ V}$ rail) subtracts a baseline $2.436\text{ mV}$ zero point, ensuring maximum ADC dynamic range resolution across pasteurization temperatures.   Automated Thermal Classification: Employs comparative logic to categorize process states with concurrent LabVIEW GUI indicators and NI myRIO onboard hardware LEDs:   Raw Milk ($T < 60\text{ }^\circ\text{C}$): Under-pasteurized; asserts LED0.   Pasteurization Zone ($60\text{ }^\circ\text{C} \le T \le 75\text{ }^\circ\text{C}$): Optimal thermal inactivation band; asserts LED1.   High-Heat Treated Milk ($T > 75\text{ }^\circ\text{C}$): Overheating warning (protein denaturation risk); asserts LED2.   Dynamic Stability & Process Tracking:Rate of Change Analysis: Uses shift registers to compute $\vert{}T(n) - T(n-1)\vert{}$; fluctuations $\le 0.5\text{ }^\circ\text{C}$ denote process stability.   Pasteurization Time Counter: Accumulates total residence time within the active pasteurization window.   Quality Index (%): A normalized metric quantifying proximity to ideal setpoint temperatures.
